# CV à télécharger

Dépose ici ton CV en PDF. Le bouton « Télécharger mon CV » n'apparaît que si un fichier est présent.

| Fichier        | Utilisé pour                    |
| -------------- | ------------------------------- |
| `cv-fr.pdf`    | version française               |
| `cv-en.pdf`    | version anglaise                |
| `cv-nl.pdf`    | version néerlandaise            |
| `cv.pdf`       | repli si la langue n'a pas le sien |

Un CV publié est public et indexable : retire l'adresse postale, la date de naissance
et le numéro de téléphone si tu ne veux pas qu'ils circulent.
